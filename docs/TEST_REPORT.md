## 正常输入战役通关

固定种子 20261023。机器人通过 Input 动作集合提交移动、跳跃、攻击、防御、闪避、拾取与技能；通过真实的奖励/商店接口选择与购买。运行真实 Game.step、AI、碰撞、伤害、增援、关卡推进和结算。

- 最终 screen=result、success=true、level=6。
- 三位 Boss 实际击败记录：gatekeeper、commander、shadowlord。
- 实际最高阶段：守门人 2、统领 2、最终首领 3。
- 击败 250 名对手，最终得分 82532，最高连击 144。
- 游戏推进时间 686 秒；机器人具有精确预警观察、不计菜单思考时间且不走全部奖励支路，**不能当作普通玩家平均时长**。15–25 分钟为设计目标，仍需更多真人数据校准。
- 没有修改玩家耐久/坐标、删除敌人、直接设置封锁完成或调用胜利结算。测试环境只替换 DOM/音频宿主，不替换游戏规则。

## 技能与握持专项

三技能图标和 Canvas 特效共用 SKILL_GLYPHS。冲击掌显示向前推进掌印，影步显示疾影图形、残像及交叉刃光，震地显示冲击环、裂纹和碎石。只在技能有效期首帧生成视觉事件；视觉无伤害逻辑；暂停时年龄不推进、重试创建新视觉集合。

长杆和重锤的双手通过刚性杆轴约束，分别保持 18 / 14 像素握点间距。手臂先画、武器后画、握指最后覆盖，避免武器悬在手背外。回归覆盖多动作的起手/有效/收招采样。浏览器截图观察到长杆；重锤缺少逐帧近景证据，因此不宣称每帧均经过人工视觉验收。

## 竞技场压力结果

固定 1/60 秒提交 162000 帧正常输入；机器人正常失败后重开 12 次。测试不是无伤/无限生命，也不是一局不死运行 45 分钟。对象数每 300 帧采样：敌人 10、粒子 56、掉落 12、投掷物 3、技能视觉 1 的采样峰值。强制 GC 后 Node 堆样本首尾约 7913KB / 8202KB。此结果支持逻辑对象回收有效，**不能代替真实浏览器 GPU、DOM、音频内存的长期测量**。

生产代码硬上限：粒子 260、地面武器 32、投掷物 50、技能视觉 12；死亡敌人两秒后移除，波次切换和重试重建集合，音源同时最多 45 个并在结束后断开。
